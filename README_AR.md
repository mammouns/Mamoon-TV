# مامون TV — مشروع Android أولي

نسخة أولية لعرض نتائج كرة القدم باستخدام Football API، بواجهة عربية داكنة.

## ماذا تحتوي؟
- واجهة Android أصلية بلغة Kotlin.
- نتائج اليوم، المباريات القادمة، والنتائج المباشرة.
- إدخال مفتاح API وحفظه محليًا على الجهاز.
- رسائل واضحة عند عدم وجود بيانات أو عند رفض صلاحية الوصول.
- GitHub Actions لبناء ملف APK تلقائيًا.

## المتطلبات
- مفتاح API من: https://footballapi.org/key
- للبناء المحلي: JDK 17 وGradle 8.9 وAndroid SDK 35.
- إذا كنت تعمل من الهاتف فقط، ارفع ملفات هذا المشروع إلى مستودع GitHub، ثم افتح تبويب Actions وشغّل `Build Mamoon TV APK`. بعد نجاح البناء نزّل artifact باسم `Mamoon-TV-debug-apk`، واستخرج ملف `app-debug.apk`.

## حدود الباقة
بحسب توثيق Football API الحالي، المفتاح المجاني يتيح هذا الموسم من الدوري الإنجليزي الممتاز بحد 50 طلبًا يوميًا. واجهة النتائج المباشرة `/v1/live` تتطلب عضوية مدفوعة. قد تظهر رسالة ترقية عند اختيار المباشر أو منافسات غير مشمولة.

## ملاحظة أمنية مهمة
هذا نموذج أولي للاختبار. المفتاح الذي تدخله محفوظ محليًا ويُرسل من الجهاز مباشرة إلى API، وهذا مناسب للتجربة الشخصية فقط وليس لتطبيق منشور للعامة. قبل النشر، ضع API key في خادم وسيط خاص بك ولا تضمّنه في التطبيق.

## البناء
المشروع لا يتضمن Gradle Wrapper. في بيئة فيها Gradle 8.9:
```bash
gradle assembleDebug
```
الناتج:
`app/build/outputs/apk/debug/app-debug.apk`
